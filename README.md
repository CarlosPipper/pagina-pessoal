# Página Pessoal

Página pessoal desenvolvida para apresentar informações profissionais, habilidades e projetos.

## Objetivo

Praticar desenvolvimento web utilizando HTML e CSS e criar uma página que possa ser utilizada como apresentação profissional.

## Tecnologias

* HTML5
* CSS3

## Conteúdo

* Apresentação pessoal
* Habilidades
* Projetos
* Informações de contato
